# Elstaru

An Android application specifically designed and optimized for foldable form factors.

## Overview
Elstaru focuses on delivering a seamless experience across varying screen sizes, with a primary focus on the folding and unfolding transitions of modern devices.

## Primary Target Devices
- **Samsung Galaxy Z Fold 6 & 7** (and newer)
- **Google Pixel Fold**
- Other large-screen and foldable Android devices

## Technical Specifications
- **Compile & Target SDK:** 37 (Android 15)
- **Minimum SDK:** 30
- **UI Framework:** Jetpack Compose
- **Design System:** Material 3 with Adaptive Library integration
- **Build System:** Gradle (Kotlin DSL) with Version Catalog and Configuration Cache enabled.
